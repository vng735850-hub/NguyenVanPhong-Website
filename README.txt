PHONG WEB - LINK4M UPGRADE

FILES
- index.html: original website retained, updated styling and Link4M API calls
- server.js: backend proxy for Link4M, shared stats, admin login and shared config
- package.json: Node dependencies
- render.yaml: Render Web Service + persistent disk configuration

IMPORTANT SECURITY
1. The Link4M API token pasted in chat must be revoked/rotated in Link4M.
2. Never place the API token in index.html. Set it in Render Environment as LINK4M_API_TOKEN.
3. Set ADMIN_PASSWORD to a new strong password in Render Environment.
4. JWT_SECRET is generated by render.yaml; if creating service manually, set a long random secret.

DEPLOY
This project must run as a Render Web Service (Node), not as a Static Site.
- Build Command: npm install
- Start Command: npm start
- Node: 20+
- Persistent Disk mount path: /var/data
- Environment variables: SITE_URL=https://nvp105.onrender.com, DATA_DIR=/var/data,
  LINK4M_API_TOKEN=<NEW ROTATED TOKEN>, ADMIN_PASSWORD=<NEW STRONG PASSWORD>,
  JWT_SECRET=<LONG RANDOM SECRET>

If importing render.yaml, review the service name and plan. Persistent disk is required
for shared config and global stats to survive deploys/restarts. Render persistent disks
may require a paid plan.

LINK4M FLOW
Each destination creates/caches a Link4M short link whose destination is:
https://nvp105.onrender.com/#/return/<key>
On return, existing thank-you and success pages are preserved, and LAY FILE opens
that destination's original file URL.

STATS LIMITATION
The Developers API documentation supplied describes only link shortening. It does
not document a Link4M click/view statistics endpoint. This version therefore records
website visits, successful returns, and file button clicks on this backend. These are
our website-side counts, NOT Link4M's own reported view count.

ADMIN
Admin password is set by the server environment variable ADMIN_PASSWORD. The browser
receives a time-limited signed session token; the Link4M API token stays server-side.
Config is shared through the server JSON store on the persistent disk.
